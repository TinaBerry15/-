# Rail Shop

出品中の服の写真を、3D のハンガーラックに掛けて見せるストア。
ビルド工程なし・依存パッケージなし (three.js は同梱)。

```bash
npm start          # http://127.0.0.1:8790
```

- ストア: `/` — ラックを横に流す → 正面の 1 着をクリック → 詳細 (写真切替・ドラッグで回転)
- 管理: `/admin` — 写真を選んで商品名と価格を入れるだけ

購入ボタンはメルカリの商品ページへ飛ぶだけで、**決済・発送はメルカリ上で行う**。
このサイト自体は決済を持たない。

## 商品の追加

1. `/admin` を開く
2. メルカリに載せているのと同じ写真を選ぶ (最大 10 枚。1 枚目がラックに掛かる)
3. 商品名・価格・メルカリの商品ページ URL を入れて「ラックに掛ける」

1 つも登録していない間は、ストアに見本が表示される。1 つ登録すると見本は消える。

### 「背景を透かす」について

四辺から、縁の色に近い部分を塗りつぶして消すだけの単純な処理。

- 効く: 白い壁・床・単色のシーツに平置き / 壁掛けした写真
- 効かない: 柄のある背景、影が濃い写真、服と背景の色が近い写真 (白 T を白壁、など)

うまく抜けなかった写真は自動で元のまま使う (プレビューに「透過」の印が付かない)。
背景つきの写真は、角を落としたカードとしてそのまま掛かる。

## 操作

| | |
|---|---|
| ラックを流す | ドラッグ / 横スクロール / ← → / 左右の矢印 |
| 詳細を開く | 正面の服をクリック / Enter / VIEW ITEM |
| 写真を切り替える | サムネイル / ← → |
| 服を回す | 詳細でドラッグ (離すと表か裏に戻る) |
| 閉じる | Esc / × |

## データの置き場所

```
data/items.json     商品とショップ設定
data/uploads/       写真 (ブラウザ側で長辺 1400px に縮めてから保存)
```

`data/` は git に入れていない。**消すと商品が全部消える**ので、公開後はここをバックアップする。

### 初期在庫 (`seed/`)

`seed/` には最初から掛けておく商品が入っている。`data/` がまだ無い初回起動のときだけ、
`seed/` の中身が `data/` に写される。2 回目以降は `data/` が正で、`seed/` を書き換えても反映されない
(管理画面で直した内容を上書きしないため)。価格や URL は `/admin` の「編集」から直す。

## ネットに公開するとき

既定では自分のマシンからしか見えず、管理操作もそのマシンからしかできない。
公開するには `.env.example` を `.env` にコピーして、

```
ADMIN_TOKEN=長いランダムな文字列
HOST=0.0.0.0
```

を設定する。`ADMIN_TOKEN` を入れないまま公開しても、外からの追加・削除は拒否される
(その代わり、外出先のスマホから商品を追加することもできない)。

置き場所は「Node.js が動いて、ディスクが消えない」サーバが要る
(Render / Railway / Fly.io の永続ディスク付きプラン、VPS など)。
Vercel / Netlify のような静的ホスティングでは、商品の保存ができないので動かない。

## やっていないこと

- メルカリからの自動取り込み (公開 API が無く、ページの機械取得は規約に触れるため。写真は手で選ぶ)
- 在庫の自動同期 (メルカリで売れたら `/admin` で「売り切れにする」を押す)
- 決済
